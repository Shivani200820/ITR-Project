# MySQL Database Design

## Database Name
civicai_db

## Storage Engine
InnoDB

## Character Set
utf8mb4

## Collation
utf8mb4_unicode_ci

## Purpose

The CivicAI database stores information related to users, complaints, departments, AI analysis, notifications, and system logs. It is designed to maintain data consistency, improve performance, and support future scalability.

## Features

- Uses Primary Keys for unique identification.
- Uses Foreign Keys to maintain relationships.
- Uses indexes for faster searching.
- Supports AI analysis and complaint management.
- Designed according to Third Normal Form (3NF).
